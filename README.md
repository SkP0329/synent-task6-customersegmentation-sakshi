# Customer Segmentation using K-Means Clustering

## Project Overview
This project performs customer segmentation using the Mall Customer Dataset.

Customers are grouped based on:
- Annual Income
- Spending Score

K-Means clustering is used to identify customer groups for business insights and marketing strategies.

---

## Objective
To group customers based on purchasing behavior and spending patterns.

---

## Dataset
Mall Customer Dataset

Features Used:
- Annual Income (k$)
- Spending Score (1-100)

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## Project Workflow

### 1. Data Preprocessing
- Loaded dataset
- Checked missing values
- Selected important features
- Applied feature scaling

### 2. K-Means Clustering
- Used Elbow Method to determine optimal clusters
- Applied K-Means algorithm

### 3. Visualization
- Visualized customer clusters
- Displayed centroids

---

## Output
- Customer segments
- Cluster visualization
- Business insights

---

## Insights
- High-income high-spending customers are premium customers.
- Low-income low-spending customers need different marketing approaches.
- Businesses can target customers more effectively using segmentation.
